# Спринт 1 — основы Python

Учебные задания по основам Python: обработка строк, списков и словарей, условия,
циклы, методы и классы.

## Состав проекта

- `task_1.py` — подсчёт суммарного времени;
- `task_2.py` — класс тестировщика;
- `task_3.py` — работа со словарём чемпионов мира;
- `task_4.py` — обработка списков задач;
- `task_5.py` — класс для формирования тест-кейсов.

Каждое задание запускается отдельно:

```bash
python task_1.py
```
