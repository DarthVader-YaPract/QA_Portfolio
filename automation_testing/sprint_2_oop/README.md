# Спринт 2 — объектно-ориентированное программирование

Итоговая версия учебных заданий по ООП после исправлений по результатам ревью.

## Состав проекта

- `task_1.py` — наследование тест-кейсов;
- `task_2.py` — наследование классов фильмов;
- `task_3.py` — множественное наследование и расчёт баллов;
- `task_4.py` — классовые методы для расчёта зарплаты;
- `task_5.py` — полиморфизм на примере спортивных результатов.

Каждое задание запускается отдельно:

```bash
python task_1.py
```
