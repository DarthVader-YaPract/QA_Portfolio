# Спринт 3 — онлайн-касса

Учебная реализация класса `OnlineSalesRegisterCollector` для работы с чеком
онлайн-кассы.

Класс поддерживает:

- добавление и удаление товаров;
- подсчёт суммы чека;
- применение скидки;
- расчёт налогов по ставкам 10 % и 20 %;
- проверку и форматирование номера телефона.

Основной файл проекта — `online_sales_register.py`.
