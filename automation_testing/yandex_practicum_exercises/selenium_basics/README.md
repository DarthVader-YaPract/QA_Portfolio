# Основы Selenium

Выполненные упражнения из тренажёра Яндекс Практикума по работе с Selenium:

- подключение Selenium и запуск Chrome;
- поиск одного и нескольких элементов;
- применение локаторов `ID`, `CLASS_NAME`, `TAG_NAME`, `CSS_SELECTOR` и
  `XPATH`;
- заполнение полей и нажатие кнопок;
- получение текста и атрибутов элементов;
- явные и неявные ожидания;
- прокрутка до элемента;
- добавление и изменение cookies;
- изменение изображения профиля.

Незавершённые файлы с пропусками в этот каталог не включены.

## Учётные данные

Email и пароль учебного пользователя не сохраняются в репозитории. Перед
запуском упражнений с авторизацией укажите переменные окружения:

```powershell
$env:MESTO_EMAIL = "email"
$env:MESTO_PASSWORD = "password"
```

## Запуск

Для выполнения упражнений необходимы Python, Selenium и Google Chrome:

```bash
python find_element_exercise_1.py
```
