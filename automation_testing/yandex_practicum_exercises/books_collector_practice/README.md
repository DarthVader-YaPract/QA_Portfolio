# BooksCollector — тренировочные тесты

Расширенный тренировочный набор юнит-тестов для класса `BooksCollector`.
Проверяются добавление книг, назначение жанров, выборка детских книг и работа
со списком избранного. Для повторяющихся сценариев используется параметризация.

Эта версия сохранена как дополнительная практика. Итоговый проект четвёртого
спринта находится в соседнем каталоге
`sprint_4_unit_testing_books_collector`.

## Запуск

```bash
pytest -v tests.py
```
