# Задачник Яндекс Практикума

В разделе собраны небольшие выполненные упражнения из тренажёра по Python,
Git и `pytest`. Служебные файлы IDE, кэши и повторяющиеся копии исключены.

## Состав

- `python_git_basics` — первые упражнения с файлами, Git и простым скриптом на
  Python;
- `pytest_hobbits` — параметризованные тесты для статусов участников программы
  лояльности;
- `selenium_basics` — поиск элементов, ожидания, cookies и взаимодействие с
  учебным веб-приложением;
- `books_collector_practice` — расширенный тренировочный набор юнит-тестов для
  класса `BooksCollector`.

Основные спринтовые проекты хранятся отдельно в каталоге
`automation_testing`, поэтому здесь находятся только дополнительные
тренировочные задания.
