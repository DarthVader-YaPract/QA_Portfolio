# Ручное тестирование

В разделе находятся пять итоговых учебных проектов по ручному тестированию.
Для каждого проекта подготовлены краткое описание и папка `artifacts` с
результатами работы после последних доработок.

Черновики, материалы курса, скринкасты, дистрибутивы и повторяющиеся версии
документов в портфолио не включены.
