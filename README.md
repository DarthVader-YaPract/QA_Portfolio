# QA Portfolio — Андрей Калашов

Портфолио учебных проектов по ручному тестированию.

В репозитории собраны итоговые версии работ после ревью: чек-листы, тест-кейсы,
баг-репорты и отчёты о тестировании. Черновики, учебные материалы, видео,
дистрибутивы и повторяющиеся версии не включены.

## Проекты

| Проект | Объект тестирования | Результаты |
| --- | --- | --- |
| [Спринт 1](manual_testing/sprint_1_regression/) | Веб-приложение «Место» | Регрессионное тестирование, ретест и баг-репорты |
| [Спринт 2](manual_testing/sprint_2_test_design/) | «Яндекс Маршруты» | Тест-анализ, тест-дизайн, тест-кейсы и баг-репорты |
| [Спринт 3](manual_testing/sprint_3_web_testing/) | Каршеринг в «Яндекс Маршрутах» | Тестирование веб-интерфейса и логики бронирования |
| [Спринт 4](manual_testing/sprint_4_mobile/) | Мобильное приложение «Яндекс Метро» | Мобильное тестирование и отчёт о результатах |
| [Спринт 5](manual_testing/sprint_5_api/) | API «Яндекс Прилавок» | API-тестирование и отчёт о результатах |

## Навыки

- анализ требований;
- составление чек-листов и тест-кейсов;
- классы эквивалентности и граничные значения;
- оформление баг-репортов;
- регрессионное тестирование и ретест;
- тестирование веб- и мобильных интерфейсов;
- тестирование API.
